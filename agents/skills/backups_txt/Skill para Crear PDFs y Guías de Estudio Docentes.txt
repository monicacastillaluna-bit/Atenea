description: Estructura y redacta contenidos para documentos descargables (PDF), como guías de estudio y manuales técnicos, con un tono profesional y académico para Iberoamérica.

Skill: Crear PDFs y Guías de Estudio Docentes

Cuándo usar este skill

Cuando se necesite transformar un contenido de curso en un material de lectura descargable.

Para crear manuales de procedimientos administrativos o pedagógicos.

Cuando el usuario pida una "guía de estudio", "e-book" o "documento de apoyo" para su formación.

Inputs necesarios

Contenido base: Información técnica o pedagógica a procesar.

Tipo de documento: (Ej. Guía de aprendizaje, Manual de usuario, Compendio teórico).

Público específico: (Ej. Docentes de secundaria en el Caribe, Directivos en España).

Referencia de estilo: Consultar obligatoriamente la skill definir-voz-estilo-edtech.

Workflow

Estructura Arquitectónica: Organizar el contenido en: Portada -> Introducción -> Índice conceptual -> Desarrollo por bloques -> Conclusiones -> Referencias.

Curaduría Pedagógica: Asegurar que cada sección del PDF tenga un objetivo de aprendizaje claro.

Adaptación de Voz: Aplicar el tono de "experta en gestión" (autoridad con calidez), eliminando párrafos excesivamente largos.

Formateo para Lectura: Insertar llamadas de atención ("Sabías que...", "Dato clave") para romper la monotonía del texto.

Revisión de Neutralidad: Verificar que términos como "asignatura", "materia" o "clase" se usen de forma que se entiendan en toda Iberoamérica.

Instrucciones

Nivel de libertad: Baja (Pasos exactos). El documento debe seguir una jerarquía visual clara (H1, H2, H3).

Estilo de redacción: Usar la voz activa. En lugar de "Se recomienda que el docente haga...", usar "Como docente, te recomendamos...".

Extensión de párrafos: Máximo 4-5 líneas para garantizar la legibilidad en pantallas (lectura digital de PDF).

Citas y Referencias: Utilizar un formato simplificado de normas APA para dar respaldo académico al material.

Output (formato exacto)

Presentar el contenido listo para diagramar:

Título del Documento:

Resumen Ejecutivo (Abstract): Máximo 100 palabras.

Cuerpo del Documento: Texto estructurado con títulos y subtítulos.

Elementos destacados: Cuadros de texto sugeridos para "Tips" o "Recuerda".

Bibliografía Sugerida: Lista de 3-5 fuentes o enlaces de interés.

Manejo de errores

Si el contenido original es muy informal, la skill debe preguntar: "¿Deseas mantener este tono o lo elevo al estándar profesional de gestión universitaria?".

Si falta la conclusión, la skill debe generarla automáticamente basada en los puntos clave del desarrollo.
