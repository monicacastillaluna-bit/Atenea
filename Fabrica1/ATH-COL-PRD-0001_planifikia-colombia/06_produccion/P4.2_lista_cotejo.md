# Lista de cotejo · ¿Mi planeación está completa?

Pásala ANTES de derivar las tres salidas del planeador — y otra vez antes de entregar a
coordinación. Marca: ✅ completo · ⚠️ parcial · ❌ falta.

## Bloque A · Anclaje al DBA (el núcleo)

| # | Ítem | ✅ ⚠️ ❌ |
|---|---|---|
| 1 | Cada unidad de la planeación cita el DBA exacto (área, grado, número y enunciado textual) | |
| 2 | Las evidencias de aprendizaje del DBA aparecen como criterios observables de la unidad | |
| 3 | La secuencia de DBA del año está justificada (no sigue la numeración por inercia) | |

## Bloque B · Coherencia de las tres salidas

| # | Ítem | ✅ ⚠️ ❌ |
|---|---|---|
| 4 | Plan de área, plan de aula y malla derivan del mismo planeador maestro (sin elementos huérfanos) | |
| 5 | Cada salida contiene solo lo que le es propio (según el mapa P1.2) — sin duplicar trabajo | |
| 6 | Los tres formatos citan los mismos DBA — un coordinador puede rastrear la coherencia en minutos | |

## Bloque C · Articulación institucional (PEI y SIEE)

| # | Ítem | ✅ ⚠️ ❌ |
|---|---|---|
| 7 | La planeación se articula con el enfoque y las metodologías del PEI | |
| 8 | Los criterios de evaluación conectan con el SIEE institucional (escala, periodos, comisiones) | |
| 9 | Hay coherencia declarada con los EBC del grupo de grados (los DBA como ruta anual hacia ellos) | |
| 10 | La planeación prevé ajustes por ritmos de aprendizaje (la flexibilidad que los DBA permiten) | |

📌 Lectura del resultado: 9-10 ✅ → deriva las salidas con confianza · 6-8 → revisa tus ⚠️ con
la rúbrica de calidad (P4.3) · menos de 6 → vuelve al bloque con más ❌ (casi siempre es el A:
sin DBA citado, lo demás flota).
