# Las 3 plantillas de salida (llenar una vez, pegar tres veces)

Cada plantilla está **pre-mapeada** a los campos del planeador maestro (P2.1): junto a cada
sección te decimos de qué columna del planeador sale. Si tu institución usa formatos propios,
no pelees con ellos: usa este mapeo como guía de dónde pegar cada cosa — el contenido es el
mismo, cambia el orden de las casillas.

📌 Recuerda el fundamento: los documentos oficiales de los DBA no exigen ningún formato
específico — los formatos son de tu institución. Estas plantillas existen para que el formato
no te cueste trabajo pedagógico adicional.

# Plantilla A · Plan de área

## 1. Identificación
Institución, área, grado, docentes del área, año, calendario. ← *datos de contexto del planeador*

## 2. Articulación institucional
Enfoque del PEI que el área activa; coherencia con los EBC del grupo de grados (los DBA como
ruta año a año hacia ellos). ← *campos PEI del planeador*

## 3. DBA del año y secuencia por periodos
Tabla: periodo → DBA citados (número + enunciado textual) → justificación de la secuencia.
← *columnas "Periodo", "DBA citado" y "¿Por qué este DBA ahora?" del planeador*

## 4. Evaluación del área
Criterios generales y su articulación con la escala y periodos del SIEE. ← *columna
"Evaluación (puente SIEE)" del planeador + rúbricas P4.1*

## 5. Recursos y ajustes
Recursos del área; previsión de ajustes por ritmos de aprendizaje. ← *columnas "Recursos" y
"Ajustes por ritmos"*

# Plantilla B · Plan de aula (parcelador)

## 1. Encabezado
Docente, grado/grupo, área, periodo, semanas que cubre. ← *datos de contexto*

## 2. El DBA en curso
Número + enunciado textual + evidencias priorizadas para este grupo. ← *columnas "DBA citado",
"Evidencias" y "Evidencia observable en mi grupo"*

## 3. Secuencia de actividades
Qué harás por semana/sesión, con recursos concretos. ← *columna "Estrategias y actividades"*

## 4. Evaluación de la ventana
Instrumento + criterios para estas semanas, alineados al SIEE. ← *columna "Evaluación"*

## 5. Ajustes y observaciones
Qué cambiaste sobre la marcha y por qué (esto alimenta la próxima revisión del planeador).

# Plantilla C · Malla curricular

Una sola cuadrícula panorámica:

| Periodo | DBA (número + enunciado corto) | Evidencias clave | Estrategia central | Evaluación |
|---|---|---|---|---|
| 1º | ← del planeador | ← del planeador | ← del planeador | ← del planeador |
| 2º | | | | |
| 3º | | | | |
| 4º | | | | |

📌 En la malla el enunciado puede ir abreviado, pero **el número del DBA nunca se omite**: es
lo que permite a cualquier lector rastrear la malla → plan de área → planeador → documento
oficial.

# 🧠 Rutina de trazabilidad (antes de entregar cualquiera de las tres)

Recorre la salida que acabas de llenar y pregunta por cada elemento: **"¿esto se rastrea al
planeador maestro?"**

- Si está en la salida y en el planeador → ✅ coherente.
- Si está en la salida pero NO en el planeador → ¿por qué está aquí? O lo agregas al planeador
  (fue una decisión real que no registraste) o lo quitas (es relleno de formato).
- Si está en el planeador pero falta en la salida → agrégalo: es contenido pedagógico que el
  formato se estaba comiendo.

💭 La incoherencia entre formatos es lo primero que una coordinación detecta ("en la malla dice
DBA 3 y en el plan de área DBA 5"). Con esta rutina, es estructuralmente imposible: las tres
salidas beben del mismo planeador.
