# P4.2 · Lista de cotejo: ¿mi planificación está completa?

Escala: ✅ completo · ⚠️ parcial · ❌ falta. Pásala al cerrar cada unidad (10 minutos). Los
ítems salen del fundamento verificado del CNEB y el Programa Curricular — no de una moda.

## Bloque A · Anclaje a la cadena CNEB

| # | Ítem | ✅/⚠️/❌ |
|---|---|---|
| 1 | Cada unidad cita la competencia y el desempeño exacto del grado (área, grado y referencia al documento oficial) | |
| 2 | El estándar del ciclo está identificado como referente de llegada (sé hacia dónde va mi grupo) | |
| 3 | La selección de desempeños del periodo está justificada por la progresión de mi grupo (no por orden de aparición en el documento) | |

## Bloque B · Coherencia de las tres salidas

| # | Ítem | ✅/⚠️/❌ |
|---|---|---|
| 4 | Unidad, sesiones y experiencia derivan del mismo planeador maestro (sin elementos huérfanos) | |
| 5 | Cada salida contiene solo lo que le es propio (según el mapa P1.2) — no hay triple digitación | |
| 6 | Las tres salidas citan los mismos desempeños — cualquier revisor rastrea la coherencia en minutos | |

## Bloque C · Evaluación formativa (Sección VII del CNEB)

| # | Ítem | ✅/⚠️/❌ |
|---|---|---|
| 7 | Cada unidad parte de una situación significativa retadora del contexto real de mis estudiantes | |
| 8 | Los criterios de evaluación derivan del estándar y los desempeños — y mis estudiantes los conocen | |
| 9 | Está prevista la evidencia que recogeré y el momento de la retroalimentación | |
| 10 | La planificación prevé oportunidades diferenciadas según el nivel real de cada estudiante | |

**Lectura del resultado:** 9-10 ✅ = lista para compartir en tu jornada de reflexión como
modelo. 7-8 = ajusta los ⚠️ antes del acompañamiento. Menos de 7 = vuelve al planeador maestro:
casi siempre el problema está en la cadena (bloque A), no en el formato.
