description: Diseña la estructura pedagógica y logística de talleres prácticos (workshops) para docentes, enfocados en el aprendizaje activo y la creación de productos educativos reales.

Skill: Crear Talleres Prácticos Docentes

Cuándo usar este skill

Cuando se necesite diseñar una sesión de "manos a la obra" (hands-on) donde el docente deba producir un resultado (ej. una rúbrica, un plan de clase con IA, un sílabo).

Para transformar una lección teórica en una experiencia de aprendizaje basada en retos o proyectos.

Cuando se requiera una guía paso a paso para un facilitador que dirigirá una sesión grupal interactiva.

Inputs necesarios

Producto final esperado: ¿Qué objeto tangible o digital habrá creado el docente al finalizar el taller?

Duración: (Ej. 90 minutos, 3 horas).

Metodología sugerida: (Ej. Aprendizaje Basado en Retos, Aula Invertida, Design Thinking).

Herramientas de apoyo: (Ej. Canva, ChatGPT, Google Docs, Moodle).

Referencia de estilo: Consultar obligatoriamente definir-voz-estilo-edtech.

Workflow

Diseño del Reto (The Challenge): Definir una situación problemática real de la gestión o docencia universitaria que el taller resolverá.

Secuencia Didáctica (Andamiaje):

Activación (15%): Dinámica de inicio para conectar con conocimientos previos.

Demostración (20%): Modelado del experto (Monica o facilitador) sobre cómo usar la herramienta o método.

Práctica Guiada (50%): Trabajo activo de los docentes con hitos intermedios de revisión.

Puesta en Común y Cierre (15%): Exhibición de resultados y feedback grupal.

Redacción de Instrucciones: Crear consignas claras, directas y motivadoras, evitando la ambigüedad.

Validación de Logística: Listar todos los insumos necesarios (plantillas, enlaces, permisos) para que nada falle en la ejecución.

Instrucciones

Tono: Empoderador y experto. Debes sonar como la mentora que guía el proceso, no como quien da una orden administrativa.

Enfoque de "Andamiaje": Asegurar que las tareas complejas se dividan en micropasos para evitar la frustración del docente.

Localización: Usar terminología técnica educativa compartida (ej. "Secuencia didáctica", "Competencias", "Evidencias de aprendizaje") válida para México, España y el resto de América Latina.

Output (formato exacto)

Presentar el diseño del taller bajo el siguiente esquema:

Título del Taller:

Reto Central: Descripción del problema a resolver.

Hoja de Ruta (Timeline):
| Tiempo | Fase | Actividad del Docente | Rol del Facilitador |
| :--- | :--- | :--- | :--- |
| 00:00 | Activación | ... | ... |

Guía de Actividades: Instrucciones detalladas para los ejercicios prácticos.

Lista de Insumos: Enlaces a recursos o carpetas necesarias.

Criterios de Éxito: ¿Cómo sabe el docente que terminó su producto con éxito?

Manejo de errores

Si el producto esperado es demasiado ambicioso para el tiempo dado, la skill debe sugerir: "Reducir el alcance a un prototipo o aumentar la duración a [X] minutos".

Si no se definen herramientas, la skill debe proponer las más adecuadas según el ecosistema tecnológico docente actual.
