name: crear-clinicas-docentes
description: Diseña sesiones de diagnóstico y resolución técnica (clínicas) para abordar problemas específicos de docencia o gestión universitaria con un enfoque clínico y experto.

Skill: Crear Clínicas de Resolución Docente

Cuándo usar este skill

Cuando un docente o directivo presente un "caso crítico" o bloqueo específico que requiera intervención experta.

Para realizar auditorías en vivo de materiales, programas o procesos administrativos.

Cuando se necesite un formato de asesoría grupal donde se analicen ejemplos reales para extraer lecciones generales.

Inputs necesarios

El "Caso" o Problema: Descripción detallada del síntoma o dificultad (ej. "Baja retención en el primer mes", "Dificultad para evaluar competencias blandas").

Evidencias: Materiales relacionados (ej. un sílabo, una grabación de clase, una base de datos).

Perfil del Consultante: (Ej. Decanos en México, profesores noveles en el Caribe).

Referencia de estilo: Consultar obligatoriamente definir-voz-estilo-edtech.

Workflow

Fase de Triaje (Diagnóstico): Identificar la causa raíz del problema mediante preguntas dirigidas.

Análisis de Evidencias: Contrastar la situación actual con las mejores prácticas de gestión y pedagogía.

Intervención Experta (Prescripción): Proponer soluciones inmediatas y ajustes a mediano plazo.

Modelado de Mejora: Mostrar cómo quedaría el elemento corregido (el "antes y después").

Protocolo de Seguimiento: Definir indicadores para saber si la "clínica" fue efectiva.

Instrucciones

Tono: "Clínico": Analítico, preciso, honesto pero profundamente empático y profesional. No juzgar, sino diagnosticar.

Nivel de libertad: Baja (Pasos exactos). Una clínica debe seguir un método riguroso para no convertirse en una charla informal.

Localización: Asegurar que los términos de gestión (ej. "Acreditación", "Rúbricas de evaluación", "Carga académica") sean los correctos para la región del caso.

Output (formato exacto)

Presentar el diseño de la clínica:

Título de la Clínica: (Ej. Clínica de Diseño de Evaluaciones).

Diagnóstico Sugerido: Resumen del problema detectado.

Estructura de la Sesión:
| Tiempo | Fase | Actividad | Notas de la Experta |
| :--- | :--- | :--- | :--- |
| 00:00 | Diagnóstico | Presentación del caso | "[Escuchar activamente sin interrumpir]" |

Prescripción Técnica: Lista de 3 a 5 cambios críticos a realizar.

Hoja de Recomendaciones: Documento breve con "medicinas" pedagógicas (recursos adicionales).

Manejo de errores

Si el caso presentado es demasiado vago, la skill debe pedir: "Por favor, adjunta una evidencia o describe un síntoma específico para realizar un diagnóstico preciso".

Si la solución propuesta es inviable administrativamente, la skill debe ofrecer una alternativa basada en la normativa universitaria estándar.
