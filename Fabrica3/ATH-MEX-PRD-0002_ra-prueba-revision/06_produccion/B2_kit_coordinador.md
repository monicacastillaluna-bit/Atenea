# Kit del coordinador

*Revise los programas de todo un plan de estudios en una tarde — y deje evidencia de que lo hizo*

**Complemento de «Resultados de Aprendizaje a Prueba de Revisión» · Atenea Grupo Educativo**

---

## Para quién es esto

Para quien no tiene que escribir sus resultados de aprendizaje, sino **revisar los de otros**:
coordinación académica, jefatura de carrera, dirección de programa, responsable de un proceso de
RVOE o de acreditación.

Su problema no es el de la docente. El suyo es de **volumen, consistencia y defensa**:

- Cuarenta programas escritos por treinta personas distintas, con criterios distintos.
- Una fecha de entrega o una visita de evaluación encima.
- La obligación de dar retroalimentación sin romper la relación con la academia.
- Y la necesidad de **demostrar que la revisión ocurrió**, no solo que se corrigió.

## El presupuesto de tiempo, sin adornos

Para un plan de 40 asignaturas:

| | Tiempo |
|---|---|
| Pasada 1 · eliminatoria | 40 min |
| Pasada 2 · calibración de nivel | 60 min |
| Pasada 3 · progresión del plan | 30 min |
| Matriz de cobertura + reporte | 60 min |
| **Total** | **≈ 3 h 15 min** |

No es magia: es **no leer cada programa completo**. La mayoría de los problemas se ven en el
enunciado, sin abrir el resto del documento.

---

# El método de las tres pasadas

La tentación es revisar programa por programa de principio a fin. Con cuarenta, eso son dos
semanas y la calidad del criterio se degrada a partir del octavo.

**Haga lo contrario: tres pasadas rápidas sobre todos, no una pasada lenta sobre cada uno.** Así el
criterio se mantiene estable y los problemas se agrupan solos.

```
Pasada 1  →  ¿el enunciado es un resultado de aprendizaje?   (forma)
Pasada 2  →  ¿está en el nivel del programa?                  (altura)
Pasada 3  →  ¿el plan progresa de primero a último semestre?  (conjunto)
```

Las tres primeras columnas se llenan mirando **solo los enunciados**. Nunca abra el programa
completo en las pasadas 1 y 2.

---

# Pasada 1 · Formato eliminatorio

**Un minuto por asignatura.** Solo busca lo que descalifica de entrada. No juzgue calidad todavía.

| # | Asignatura | Docente | Sujeto = estudiante | Verbo observable | Tiene contexto | Un verbo por RA | Entre 4 y 8 RA | Veredicto |
|---|---|---|---|---|---|---|---|---|
| 1 | | | ☐ | ☐ | ☐ | ☐ | ☐ | |
| 2 | | | ☐ | ☐ | ☐ | ☐ | ☐ | |
| 3 | | | ☐ | ☐ | ☐ | ☐ | ☐ | |
| 4 | | | ☐ | ☐ | ☐ | ☐ | ☐ | |
| 5 | | | ☐ | ☐ | ☐ | ☐ | ☐ | |

*Duplique la tabla hasta cubrir su plan.*

**Veredictos de la pasada 1:** ✅ pasa · ⚠️ corregir · ❌ reescribir

**Regla de corte:** dos ❌ en la misma fila y la asignatura va directo a reescritura. No pierda
tiempo afinando un enunciado que hay que rehacer.

> 📌 **Atajo que ahorra la mitad del tiempo:** busque primero los verbos de la lista negra
> (*conocer, comprender, saber, apreciar, interiorizar, concientizar, sensibilizar, reflexionar
> sobre, familiarizarse con, ser capaz de*). En la práctica, entre el 40 % y el 60 % de las
> asignaturas de un plan sin revisar caen ahí. Con eso ya tiene identificado su lote grande de
> trabajo.

---

# Pasada 2 · Calibración de nivel

**Minuto y medio por asignatura.** Solo sobre las que pasaron la pasada 1.

Su plan completo acredita **un** nivel del MNC (licenciatura = 6, TSU = 5, bachillerato = 3,
maestría = 7). La pregunta aquí no es si el enunciado está bien escrito, sino si **está a la altura
del título que su institución va a expedir**.

| # | Asignatura | Semestre | Nivel aparente del RA | ¿Corresponde al nivel del plan? | Observación |
|---|---|---|---|---|---|
| 1 | | | | ☐ por debajo ☐ en nivel ☐ por encima | |
| 2 | | | | ☐ por debajo ☐ en nivel ☐ por encima | |
| 3 | | | | ☐ por debajo ☐ en nivel ☐ por encima | |
| 4 | | | | ☐ por debajo ☐ en nivel ☐ por encima | |

**Lo que va a encontrar, casi con certeza:** un bloque de asignaturas «por debajo». Es el hallazgo
más común y el más fácil de corregir — se sube agregando contexto, no cambiando el verbo.

⚠️ **El caso grave es «por encima»**, y suele pasar desapercibido porque suena ambicioso. Un
resultado que el estudiante no puede alcanzar en ese semestre es un resultado que nadie va a poder
evaluar, y en revisión eso se lee como programa mal diseñado, no como programa exigente.

---

# Pasada 3 · La progresión del plan

**Media hora, sobre el plan completo.** Esta pasada no existe en ninguna revisión que se haga
asignatura por asignatura — y es la que más pesa en acreditación.

**La pregunta:** ¿los resultados de aprendizaje **escalan** de los primeros semestres a los últimos,
o el plan es plano?

Ubique cada asignatura por semestre y por nivel cognitivo predominante:

| Semestre | Recordar | Comprender | Aplicar | Analizar | Evaluar | Crear |
|---|---|---|---|---|---|---|
| 1º | | | | | | |
| 2º | | | | | | |
| 3º | | | | | | |
| 4º | | | | | | |
| 5º | | | | | | |
| 6º | | | | | | |
| 7º | | | | | | |
| 8º | | | | | | |

*Marque con una X por cada asignatura, en su nivel predominante.*

**Cómo se lee:**

| Patrón | Diagnóstico |
|---|---|
| Las X se desplazan hacia la derecha conforme baja la tabla | ✅ El plan progresa. Es lo que se espera |
| Las X se quedan en las tres columnas de la izquierda todo el plan | ❌ **Plan plano.** El último semestre exige lo mismo que el primero |
| Hay X en «Crear» desde 1º y en «Recordar» en 8º | ⚠️ Progresión invertida o desordenada. Revise la seriación |
| Las dos últimas columnas están vacías | ❌ El plan no lleva al perfil de egreso que declara |

> 💭 **Por qué esto vale la tarde entera:** un par evaluador rara vez le va a decir "su plan es
> plano" con esas palabras. Le va a decir que *"no se evidencia la progresión hacia el perfil de
> egreso"*. Es la misma observación, y esta tabla se la anticipa.

# La matriz de cobertura del plan completo

La pieza 5 del kit tiene una matriz para **una** asignatura. Esta es la del **plan entero**, y su
referente no es la asignatura: es el **perfil de egreso**.

**Nivel del MNC que acredita este plan:** ______

| Dimensión del nivel | ¿Qué asignaturas la evidencian? | Nº | ¿Suficiente? |
|---|---|---|---|
| **D1 · Conocimientos** del tipo y profundidad del nivel | | | |
| **D2 · Destrezas y habilidades** ante problemas de esa complejidad | | | |
| **D3 · Actitudes y valores**: actuación ética y con compromiso social | | | |
| **D4 · Responsabilidad y autonomía**: grado de supervisión y de qué responde | | | |

**Criterio de suficiencia sugerido:** al menos tres asignaturas por dimensión, y al menos una de
ellas en los dos últimos semestres. Una dimensión evidenciada solo en primer año no sostiene el
perfil de egreso.

**El hallazgo típico:** D1 y D2 sobran; **D3 aparece confinada a una sola materia de ética**, y D4
no aparece en ningún lado. Si su plan está así, no es un caso raro — es el caso normal, y ahora
usted lo tiene documentado antes que el evaluador.

# Cómo dar la retroalimentación sin romper al equipo

La parte técnica de este trabajo es la fácil. La difícil es que treinta docentes reciban
observaciones sobre algo que escribieron y no lo tomen como un juicio sobre su docencia.

**Cuatro reglas que funcionan:**

1. **Devuelva el criterio antes que la corrección.** Comparta la lista de cotejo del kit *antes* de
   señalar nada. Que cada docente encuentre sus propios errores es más rápido y no deja heridas.
2. **Agrupe, no personalice.** «Detectamos que en 22 asignaturas el resultado no declara la
   condición de logro» funciona. «Tu programa está mal» no.
3. **Empiece por lo que sí está bien.** En todo plan hay dos o tres programas bien redactados.
   Úselos como el ejemplo de la casa; valen más que cualquier ejemplo externo.
4. **Separe el resultado de la persona.** El problema nunca es que alguien "no sepa redactar": es
   que **a nadie le enseñaron esto**. Solo el 26 % de docentes iberoamericanos ha recibido formación
   en diseño inclusivo, y en formulación de resultados la cifra no es mejor. Decirlo en voz alta
   desactiva la mitad de la defensiva de la sala.

**Guion para abrir la reunión de academia** — para leer casi textual:

> «Revisé los resultados de aprendizaje de las 40 asignaturas del plan. No revisé su docencia ni la
> calidad de sus cursos: solo cómo están redactados los enunciados, que es lo que va a leer el
> evaluador. Encontré tres patrones que se repiten en casi todos los programas, incluidos los míos.
> Los vemos, les paso el criterio con el que revisé, y cada quien ajusta el suyo.»

# Prompt de IA para revisión en lote

Pegue este prompt en su asistente de IA junto con los resultados de varias asignaturas de una vez.

⚠️ **No pegue datos personales de estudiantes ni documentos confidenciales de su institución.** Solo
los enunciados de los resultados de aprendizaje.

```
Actúa como par evaluador de un proceso de acreditación de programas educativos
en México.

CONTEXTO
El Marco Nacional de Cualificaciones (Acuerdo 01/02/24, DOF 01-03-2024) define
resultado de aprendizaje como "expresión de lo que una persona sabe, comprende
y es capaz de hacer al culminar un proceso formativo", y describe cada nivel en
cuatro dimensiones: conocimientos; destrezas y habilidades; actitudes y valores;
responsabilidad y autonomía.

Mi plan de estudios acredita el NIVEL [NIVEL] del MNC.

TAREA
Te doy los resultados de aprendizaje de varias asignaturas, agrupados por
asignatura y semestre. Entrégame:

1. TABLA POR ASIGNATURA: nombre, nº de RA, cuántos tienen verbo no observable,
   cuántos carecen de contexto, nivel cognitivo predominante, y veredicto
   (RESISTE / CORREGIR / REESCRIBIR).

2. PROGRESIÓN: ¿el nivel cognitivo predominante aumenta conforme avanzan los
   semestres? Dime en qué semestre se rompe la progresión, si se rompe.

3. COBERTURA DEL PLAN: qué asignaturas evidencian cada una de las cuatro
   dimensiones. Señala las dimensiones con menos de tres asignaturas y las que
   no aparecen en los dos últimos semestres.

4. LOS TRES PATRONES que más se repiten en todo el conjunto, con ejemplos.

REGLAS
- No reescribas ningún resultado. Diagnostica.
- Sé estricto con la condición de contexto: es lo que más se omite.
- Si una asignatura tiene más de 8 resultados o menos de 4, señálalo.
- No inventes asignaturas ni completes las que estén incompletas.

RESULTADOS POR ASIGNATURA
[PEGUE AQUÍ]
```

# Acta de revisión

En acreditación, **haber corregido no basta: hay que demostrar que la revisión ocurrió**. Esta acta
es evidencia de proceso y toma dos minutos llenarla.

---

> 💭 **Sugerencia:** haga esta revisión **dos veces al año** y conserve las dos actas. La diferencia
> entre ambas *es* la evidencia de mejora continua que piden los organismos evaluadores — y es
> mucho más convincente que un solo documento perfecto sin historia.

---

## Lo que este kit no hace

Revisa y ordena **los enunciados** de todo un plan. No revisa si cada curso realmente los cumple.

Que las actividades y la evaluación de cada asignatura practiquen el verbo declarado es alineamiento
constructivo, y eso no se audita desde una coordinación con un formato: se construye con el
colectivo docente, asignatura por asignatura. Es un trabajo distinto y de otra escala.
